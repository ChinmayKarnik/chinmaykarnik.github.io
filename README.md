# chinmaykarnik.com

Personal site, built with [Next.js](https://nextjs.org) (App Router, TypeScript) and deployed to GitHub Pages as a static export.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Outputs a static site to `out/`.
